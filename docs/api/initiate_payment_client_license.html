Operation ID: v1_payments_scheduled_post.

Authentication: oauth2 (OAuth2).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | X-Client-Id | header | string | Yes | The API Client Identifier (Service Application Identifier). |

Request body

application/json

Property Type Required Description
provider string Yes The name (identifier) of the payment provider

This should only be used when using your own license and wish to use the Submit Authorisation Codes endpoint. If you wish to use Bud's call back then the redirect_url must be provided.
provider_types array of enum: business, retail, sandbox No One or more provider types that can be used to filter the list of providers that are shown to the customer during the connection flow. If no filter is applied, all types of provider are returned. Note that on Bud's sandbox environment, only sandbox providers will be returned.
redirect_url string No This is the url that your Customer will be redirected to when using the Bud user interface. If you wish to use your own license and callback infrastructure this parameter will have no effect and the provider_redirect_url parameter should be used instead.
scheduled_payment_details object Yes Details of the scheduled payment
scheduled_payment_details.amount object Yes The monetary amount.
scheduled_payment_details.amount.currency string Yes The three-letter ISO currency code of the monetary amount. Example: GBP
scheduled_payment_details.amount.value string Yes The value of the monetary amount. The value is formatted with the number of decimal places for the respective currency. Example: 10.98
scheduled_payment_details.recipient object Yes Details of the recipient of the payment
scheduled_payment_details.recipient.account_number string Yes Account identifier of the recipient
scheduled_payment_details.recipient.name string Yes Account holder name of the recipient
scheduled_payment_details.recipient.type enum: SortCodeAccountNumber, IBAN Yes The account type structure for the payment sender or receiver
scheduled_payment_details.reference string Yes Reference to use for the payment made through this scheduled instruction
scheduled_payment_details.requested_execution_date string (date-time) Yes Date-time (ISO 8601) the payment should be made. Must be at least one day in the future.
scheduled_payment_details.sender object Yes Details of the payment sender
scheduled_payment_details.sender.account_number string No Account identifier of the sender
scheduled_payment_details.sender.name string Yes Account holder name of the sender
scheduled_payment_details.sender.provider string No The name (identifier) of the payment provider
scheduled_payment_details.sender.type enum: SortCodeAccountNumber, IBAN No The account type structure for the payment sender or receiver
scheduled_payment_details.sender.user_id string Yes A string that can be used to uniquely identify a user within the Client's application
